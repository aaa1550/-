# 検証記録（code.txtと同じピン・長押し版）

- Arduino CLI 1.6.0
- Arduino Uno / arduino:avr:uno / AVR Boards 1.8.8
- 使用ライブラリ: IRremote 4.4.1のみ（Servoライブラリは使用しない）
- UNO向けコンパイル: 成功
- フラッシュ11076 / 32256 bytes
- 静的RAM600 / 2048 bytes（残り1448 bytes。実行時スタックの保証ではない）
- warnings allでArduinoコアnew.cppの未使用引数警告あり。スケッチ由来の警告なし。

## 元のcode.txtとの照合

公開された原本の全13本のI/Oピンと5つの操作キー値を比較して一致。
右ENA=D9、左ENB=D6、方向D12/D11/D7/D8、受信D4、ブザーD13、後方D0/D2、Echo D3、Trig D10、サーボD5。

ServoライブラリのincludeとTimer1の設定書き換えがないことを確認。サーボは元のD5へソフトウェアパルスを出し、右D9のPWM設定を保持する。

## 制御テスト

本番の単一.inoを模擬Arduino I/Oへ接続し、g++ C++11と-Wall -Wextra -Werrorでテスト。

- 前進・後退・左右旋回の長押し継続、249msでは継続、250msで停止。
- 有効リピート、NEC/NEC2、送信元照合、古いリピートでの再始動拒否。
- 回避中の長押し解除、OK、オーバーフロー、パリティ異常で停止。
- 15cm/5cm境界、強制後退、後方自動前進、加速するブザー、前後同時停止。
- 方向切替100ms停止、超音波無応答、回避3秒上限、時刻の折り返し。
- ソフトウェアサーボの模擬パルス幅、20msの再出力条件、micros折り返しを確認。
- サーボ関数がモーターPWMへ出力しないことを確認。

色分け表示から抽出したテキストと、コンパイルしたソースの一致も確認する。

## 実機未確認の点

リモコンの繰り返し間隔、配線、センサー極性、走行・停止距離、サーボの向き・保持・振動は未確認。
サーボは目標20ms周期・1500μsパルスだが、割り込みや超音波待機で幅・周期に変動がある。1回のパルス出力は約1.5msの待機を含み、超音波のpulseInは最大15ms待機する。
