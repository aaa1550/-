## 長押し関連

- 前進・後退・左右旋回それぞれの継続、最終受信249msでは継続、250msで停止。
- 有効な繰り返し受信で長押しを継続。
- NEC/NEC2の切り替わりを同じ送信元として受け付ける。
- 期限切れ時または停止後の古いリピートだけでは再始動しない。
- 違うアドレス・プロトコル・方向のリピート、未知キーでは期限を延長しない。
- 前方回避・後方回避の途中でも、長押しが途切れたら停止。
- OK、受信オーバーフロー、パリティ異常で停止。
- millisの折り返しをまたぐ期限判定。

## 維持した動作

15cm/5cm境界、強制後退、後方自動前進、15/10/5cm時600/350/100msのブザー周期、前後同時停止、方向切替100ms停止、超音波無応答、回避3秒上限と時計の折り返しを確認。

コードページの行番号・色分けを除いたテキストが、コンパイルしたソースと一致することも確認。

実機のリモコンの繰り返し間隔、受信安定性、配線、モジュールの極性、実走行、停止距離は未検証。受信が途切れたときは最終受信から250msとループ処理の遅延を含んで停止指令を出す。
