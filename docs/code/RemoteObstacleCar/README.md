# 今回の仕様版：RemoteObstacleCar（define宣言・1ファイル）

**前方15cm以内で段階的な警告、5cm以下で強制後退、後方検知で前進する版です。** 前のFlowchartRobotは5cm以下で停止する参考版でした。今回使うのは`RemoteObstacleCar.ino`です。

`code.txt`と同じように、ピン・リモコン値・距離・PWM速度・時間を先頭の`#define`へまとめました。この`.ino`だけで使え、独自のヘッダーファイルは不要です。外部ライブラリのIRremoteとServoは必要です。

## 動作

|入力・条件|動作|
|---|---|
|上（24）|前進|
|下（82）|後退|
|右（90）|右旋回|
|左（8）|左旋回|
|OK（28）|停止。自動回避中でも優先|
|前方15cmより遠い|ブザー停止、通常のリモコン操作|
|前方5cm超〜15cm以内|距離に応じてブザー。方向はリモコン操作を保持|
|前方5cm以下・後方に障害物なし|リモコンの方向を上書きして強制後退|
|後方検知・前方5cm超|リモコンの方向を上書きして前進|
|前方5cm以下・後方も検知|前後がふさがっているため停止|
|超音波無応答|停止。安全な距離として扱わない|

`code.txt`と同じ、方向キーを1回押すと動作を保持し、OKで止める操作方式です。押している間だけ動く方式ではなく、通信が途切れても最後の方向指令は保持されます。リピート信号を新しい開始操作として扱いません。

起動直後・OK停止中は、障害物があっても自動で走り出しません。距離によるブザーは停止中も鳴ります。方向指令が有効な間は、手動の後退・旋回中でも、前方5cm以下なら後退、後方検知なら前進を優先します。

## ブザーの鳴らし方

|前方距離|1回の周期|ON時間|OFF時間|
|---|---:|---:|---:|
|15cm|600ms|35ms|565ms|
|10cm|350ms|35ms|315ms|
|5cm以下|100ms|35ms|65ms|

5〜15cmの間は距離に比例して周期を短くします。15cmより遠ければ鳴りません。`delay()`を使わず、`millis()`で鳴動を管理するため、ブザーの待ち時間でリモコンとモーター制御を止めません。LOWで鳴るアクティブブザーを想定しています。

## 回避後の動作

- 前方による強制後退は、前方が15cmより離れたら停止します。
- 後方による自動前進は、後方検知がなくなったら停止します。
- 自動回避中にOKを押すと停止します。
- 回避は最大3秒で打ち切って停止します。異常時に走り続けないための初期値です。
- 回避完了・異常・打ち切り後は、古いリモコン指令を解除します。もう一度方向キーを押すと操作できます。
- 回転方向が変わるモーターは、一度PWMを0にして100ms後に新しい方向へ出力します。

回避の終了条件・最大時間・方向切替時間・速度は、今回の説明に数値指定がなかったため追加した設定です。先頭の`#define`から変更できます。

## ピン設定

|機能|使用ピン|元のcode.txtからの変更|
|---|---|---|
|IR受信|D4|同じ|
|右ENA / 速度|D5|**D9からD5へ信号線を移す**|
|右IN1 / IN2|D12 / D11|同じ|
|左ENB / 速度|D6|同じ|
|左IN3 / IN4|D7 / D8|同じ|
|ブザー信号|D13|同じ|
|後方赤外線 左 / 右|D0 / D2|同じ|
|超音波 Echo / Trig|D3 / D10|同じ|
|サーボ信号|D9|**D5からD9へ信号線を移す**|

**前の版と同じ変更済み配線を使用します。** UNOでServoライブラリがTimer1を使用するため、元のD9をモーターPWMとして使えません。IRremoteのTimer2とも競合しないD5/D6を速度制御に使用します。Servoは信号D9で正面90度を維持します。

`配線.jpg`のEcho=D2を使うと、今回の右後方D2と重複します。ここでは元の`code.txt`に合わせ、Echo=D3を採用しています。異なる配線図を重ねて接続しないでください。

6.jpgのリモコン受信信号はD10、配線.jpgの超音波TrigもD10です。両画像は別々の接続例なので、そのまま同時には使えません。統合コードはIR受信をD4に変更して使用しています。

D0はUSBシリアルのRXと共用なので、本プログラムではSerialを使用しません。書き込みに失敗する場合は電源を切ってD0の後方センサー信号線を外し、書き込み後に再接続します。D0を避ける場合は、実配線と`#define LFSensor_bl`を両方A5などの空きピンへ変更します。

後方は左右どちらかの入力がLOWなら障害物ありとします。5チャンネル追跡センサーの資料だけでは、後方障害物センサーとして使えるかは確定できません。取り付けと極性は実物で確認してください。

電源の資料ではブザーVCCは3.3V、超音波とIR受信は5V、サーボはModel X側の5Vです。実物の表記も確認し、GNDを共通にします。

## 速度の初期値

`ADVANCE_SPEED=128`、`BACK_SPEED=77`、`TURN_SPEED=77`、`AVOID_SPEED=80`です（0〜255のPWM）。前進約50%、後退・旋回約30%、回避約31%の初期値であり、実測した車速ではありません。車輪を浮かせて方向と停止を確認し、回避速度で確実に動き出すか確認してから調整してください。

## Arduino IDEで開く

`RemoteObstacleCar.ino`を開き、ボードをArduino Unoにします。IRremote 4.4.1、Servo 1.2.2でビルドを確認する構成です。ZIPでは同名のRemoteObstacleCarフォルダへ配置しています。独自ヘッダーの追加は不要です。

## 検証の範囲

本番の`.ino`を模擬I/Oで直接実行し、15cm/5cmの境界、強制後退、後方からの前進、ブザー周期、STOP、前後同時、方向切替停止、超音波失敗、指令保持、回避上限、時計の折り返しをテストしています。UNOビルド結果は同梱BUILD_CHECK.mdに記録します。

実機走行・配線・検知距離・センサー極性・ブレーキ距離は未確認です。超音波は60ms周期で読み、`pulseIn()`は最大15ms待機するため、検知・停止には遅延があります。5cmでの物理的な衝突防止を保証する値ではありません。
