## 画像の接続例を併用する際の注意

6.jpgのリモコン受信信号はD10、配線.jpgの超音波TrigもD10です。両画像は別々の接続例なので、そのまま同時には使えません。統合コードはIR受信をD4に変更して使用しています。

## 超音波配線を画像に合わせる場合

既定の統合コードは前版と同じ配線です。画像のEcho=D2を使いたい場合だけ、電源を切って以下を変更します。

1. Echo信号線をD3からD2へ移す。
2. 右後方のデジタルセンサー信号線をD2からA5へ移す。
3. `BoardPins.h`の`USE_PHOTO_ECHO_WIRING`を`true`に変更する。

A5への移動は、元画像に載っている後方センサー配線ではなく、D2の二重使用を避けるため本実装で追加した設定です。5チャンネル追跡センサーの配線はA0〜A4なので、この診断用配線とA5は重複しません。ただし追跡センサーを後方障害物センサーとして統合したという意味ではありません。

前版から共通で必要なENA D9→D5、サーボD5→D9の変更も行ってください。画像にある複数の接続例をそのまま重ねると、ENA D3とcode.txtのEcho D3、Echo D2とcode.txtの右後方D2などが重複します。

## 5チャンネルセンサーを確認する方法

ZIPの`examples/TrackerMonitor/TrackerMonitor.ino`をArduino IDEで開きます。電源を切り、D0に接続しているセンサー信号線を外します。画像通りA0/A1/A2/A3/A4、5V、GNDを接続し、シリアルモニターを115200bpsにします。

IR1〜IR5の値が200msごとにCSVで出ます。`0=LOW、1=HIGH`の生値なので、白い床・黒い線・実際の対象物をそれぞれ近づけ、反応と検知距離を確認できます。LOWを一律に「後方障害物」とは扱いません。

この診断は改訂版のモーターPWM D5/D6を0、方向12/11/7/8をLOWへ初期化します。統合走行スケッチとは別の診断プログラムです。モーター電源を切った状態でセンサーの確認を行ってください。実機での動作は未検証です。

## 電源の確認

資料では、ブザーモジュールのVCCは3.3V、HC-SR04・IR Receiver・Trackerは5V、SG90サーボはModel X側の5Vに接続されています。全モジュールを一律に3.3Vまたは5Vへまとめず、実物の端子表記も確認してください。GNDは共通です。プログラムで電源電圧は設定できません。

## 設計上の限界

後方にどのセンサーをどの向きで取り付けているか、画像からは確定できません。統合コードの後方判定は、引き続き「指定した2本のデジタル入力が障害物検知でLOWになる」前提です。現物が追跡センサーの場合、床の反射を障害物と誤認し得るため、上記診断で用途と取り付けを確認する必要があります。
