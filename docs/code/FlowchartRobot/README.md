# フローチャート準拠版 / FlowchartRobot

公開された `code.txt`（7134バイト）と、元のフローチャート4枚を確認して作成したArduino UNO用スケッチです。元の資料は上書きしていません。

## 開き方

ZIPを展開し、`FlowchartRobot/FlowchartRobot.ino`をArduino IDEで開きます。同じフォルダの`FlowchartLogic.h`も必要です。ボードはArduino Uno。ライブラリはArduino-IRremote 4.4.1、Servo 1.2.2を基準にしています。

## 配線で必ず確認するところ

**元のcode.txtから2本の信号線を入れ替えます。電源を切ってから変更してください。** UNOではServoライブラリがTimer1を使い、D9/D10のモーターPWMを使用できなくなるためです。

|機能|元のcode.txt|このスケッチ|
|---|---|---|
|右モーター速度 / ENA|D9|**D5へ変更**|
|サーボ信号 / S|D5|**D9へ変更**|
|右方向 IN1 / IN2|D12 / D11|D12 / D11|
|左速度 ENB|D6|D6|
|左方向 IN3 / IN4|D7 / D8|D7 / D8|
|リモコン受信|D4|D4|
|ブザー（LOWで鳴るタイプ）|D13|D13|
|後方赤外線 左 / 右|D0 / D2|D0 / D2|
|超音波 Echo / Trig|D3 / D10|D3 / D10|

取り込まれた説明画像は、ENA=D3・Echo=D2・サーボ=D9など、code.txtと異なる配線です。本実装は上表を採用しています。画像をそのまま併用せず、実機の配線を上表に合わせてください。後方のセンサーは、障害物検知時にLOWを出すデジタルセンサーを前提とします。写真の5チャンネル追跡センサーが、そのまま後方障害物検知として使用できるとは確認していません。

D0はUSBシリアルと共用です。本スケッチはSerialを使いません。書き込みに失敗する場合は電源を切ってD0のセンサー信号線を外し、書き込み後に再接続します。D0の干渉を避けたい場合は、配線と`LFSensor_bl`を両方A0へ変更できます。

## フローチャートとの対応

メイン順は、リモコン→超音波→後方赤外線→車両状態→ブザー→行動です。超音波は60ms周期、後方赤外線は毎ループ読みます。超音波待機後にもリモコンを読み、STOPを出力前に反映します。

|状態|右モーター|左モーター|
|---|---:|---:|
|上 / 前進|50%|50%|
|下 / 後退|-30%|-30%|
|左 / 左旋回|30%|-30%|
|右 / 右旋回|-30%|30%|
|前方5cm超〜15cm以下の回避|-10%|-10%|
|後方のみ障害物ありの回避|10%|10%|
|STOP / 無操作 / 危険・異常|0%|0%|

RMは図に合わせて0=停止、1=上、2=下、3=右、4=左です。Mは0=停止、1=前方警告/回避、2=後方警告/回避、3=前進、4=後退、5=左旋回、6=右旋回、7=前後同時、8=測定失敗です。M=1でも距離5cm以下では停止します。

ブザーは障害物または測定失敗で鳴らします。50msの警告音を2回、600ms周期で繰り返します。`tone()`は使わず、LOWで鳴るアクティブブザーを前提にします。

## 原図をそのまま転記しなかった箇所

- 超音波図の「15cmより遠い→両フラグ1」は、距離分類として矛盾するため「障害物なし」に修正。フラグの使い回しを避けて状態を列挙型にしました。
- 5cm以下は、これまでの緊急停止要件と原図の境界に合わせて停止。5cm超〜15cm以下だけ低速回避します。
- 前後に同時に障害物がある場合は停止。元code.txtのように先のifへ入って後退したり、その場旋回したりしません。
- 起動直後やSTOP中は、障害物があっても自動で走り出しません。操作が有効な間だけ回避します。
- 回避は100ms停止してから反対方向10%へ移行し、障害物が解消したら停止します。回避上限は停止時間を含め1500ms。完了・異常停止後は、押しっぱなしのリピートでは再始動せず、新たな方向操作が必要です。
- 受信が350ms途切れたら停止します。元コードの「最後の指令を無期限に保持」を変更し、原図の無操作停止に対応しました。リモコンがリピートを送らない機種では、短時間ずつ動くため実機確認が必要です。
- 超音波無応答を999cmの安全な距離として扱わず、異常停止します。
- `#define distancelimit 10;`末尾のセミコロンと、loop内の`/状態...`を修正しています。

100ms・350ms・1500ms・60msとブザー周期は、原図に時間指定がないため追加した初期値です。10%のPWMでは実機が動かない可能性があります。勝手に速度を上げず、車輪を浮かせて始動と方向を確認した後、必要な値を決めてください。

## 検証と制約

制御ロジックはホストC++11で、距離境界・手動速度・前後回避・停止優先・前後同時・計測失敗・通信切れ・再操作・回避上限・時計の折り返しをテストしています。Arduino UNO向けクロスコンパイルも成功しています（AVR Boards 1.8.8、IRremote 4.4.1、Servo 1.2.2）。詳細は同梱BUILD_CHECK.mdを確認してください。実機での配線、センサー極性、リモコン、制動距離、車両走行は未検証です。

`pulseIn`は最大15msブロックし、超音波測定は60ms周期です。障害物検知・停止指令にはその分の遅延があり、物理的な即時停止を保証するものではありません。側方には障害物センサーがありません。
