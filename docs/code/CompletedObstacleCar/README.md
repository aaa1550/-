# 完成コード＋障害物検知追加版（サーボなし）

オンライン保存した「完成コート.txt」（ユーザーの完成コード）を土台に、同じく保存された7枚のフローチャートの障害物検知を追加した版です。使うスケッチは `CompletedObstacleCar.ino` です。Arduino UNO / Arduino-IRremote 4.4.1でコンパイル確認済み。実機走行は未検証です。

## 元のコードを残した範囲

元のコードの行は削除・変更せず、追加だけで統合しています。stopMotors / cancelMovement / checkHoldTimeout / getDirection / sameRemote / readRemote / driveMotors の7関数は本文が元と一致します。setupにセンサー初期化を1行追加し、loopに状態更新と障害物による出力の呼び出しを追加しました。元の3行（readRemote / checkHoldTimeout / driveMotors）も残っています。

リモコンのボタン値24・82・90・8・28、通常走行と旋回のPWM180、250msの長押し判定、逆転前100ms停止を維持しています。追加部分は「【追加】」とコメントしています。元の完成コート.txt、元画像、以前のスケッチは保持しています。

## 今回の調整

前方の回避開始距離を5cmから10cmへ早め、回避速度をPWM26から100へ引き上げました。前方で後退、後方で前進します。警告開始は15cmのままです。画像原本の5cm・回避10%から変更した調整値です。前後が同時にふさがった場合は停止します。

## 図から補った点・元コードを優先した点

- 図の通常前進50%・後退と旋回30%は採用せず、依頼どおり元のMOVE_SPEED / TURN_SPEED = 180を維持しました。旧回避出力26ではモーターが動き始めず停止に見える場合があるため、回避出力を100に引き上げました。実機でAVOID_SPEEDを確認してください。
- 元のOK停止・長押し解除を優先し、停止中に障害物だけで自走させません。回避中も最終有効受信から250msで停止します。測距待機などのループ処理時間が加わる場合があります。
- 前後同時検知、超音波無応答は停止にします。超音波は60msごと、応答待ちは最大15msです。
- 超音波の図で省略されているSR1/SR2の解除を毎回設定します。10cmを超えるとSR1はfalse、15cmを超えると両方falseになります。無応答を0cmとして扱いません。
- 図の状態判定どおり毎回判断します。前方が10cmを超えたら、または後方検知が消えたら、長押しが続いている元の操作へ戻ります。以前の別コードの「15cmまで後退して停止」「3秒で回避終了」はこの版には入れていません。
- ブザーの図に加え、以前の指定「近づくほど速く」を維持しました。15cm=600ms周期、12.5cm=350ms、10cm以下または後方検知=100ms、ON35msです。delayを使わずmillisで制御します。停止中も障害物の警告は鳴ります。

## 使い方

1. Arduino IDEでIRremote 4.4.1を導入し、ボードをArduino Unoにします。
2. CompletedObstacleCarフォルダーのCompletedObstacleCar.inoを開きます。独自ヘッダーは不要です。
3. 元の配線を確認して書き込みます。
4. 上・下・右・左を長押しして動作し、離すと約250msで停止します。OKでも停止します。
