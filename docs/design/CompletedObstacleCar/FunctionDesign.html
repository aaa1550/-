uint32_t lastReceivedAt新規方向または有効リピートを受けた現在時刻に更新する。

driveMotors

処理内容長押し無効またはSTOPなら停止する。前進・後退・右旋回・左旋回から左右の符号付き出力を求める。適用済み出力と回転方向が逆なら一度停止する。停止後100ms未満なら出力せず終了し、100ms以上で方向端子とPWMを設定する。
関数形式void driveMotors()
入出力種類形式内容
引数—引数なし。
戻り値void戻り値なし。
入力Direction requested; bool holdActiveリモコンの方向指令と長押し有効状態。
int / bool / uint32_tappliedRight、appliedLeft、stopTimingActive、stoppedAt。MOVE_SPEEDとTURN_SPEEDは180。
出力PWM値（0～255）右D9・左D6へ180、または停止時0を出力する。
HIGH / LOW右D12/D11・左D7/D8で回転方向を設定する。
int appliedRight, appliedLeft前進(+180,+180)、後退(−180,−180)、右(−180,+180)、左(+180,−180)。
bool stopTimingActive; uint32_t stoppedAt逆転待ちを設定し、100ms経過したら待機フラグを解除する。
ソースファイルCompletedObstacleCar.ino
呼び出し関数stopMotors() millis() digitalWrite() analogWrite()
備考障害物回避が不要な場合にloop()から呼ぶ。通常速度は元コードの180を維持。

出力float SD前方距離（cm）。無応答時は−1。
bool distanceValid応答ありならtrue、無応答ならfalse。
bool SR1, SR2SR1：有効距離10cm以下。SR2：有効距離10cm超～15cm以下。毎回解除も更新。
bool sensorStarted; uint32_t lastSensorAt測距済みフラグと、今回測距を開始した時刻。
