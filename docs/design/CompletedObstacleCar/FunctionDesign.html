関数設計書：完成コード＋障害物検知

コードへフローチャートへ

元の7関数は変更なし。setupとloopは呼び出しを追加。サーボなし。通常速度は元コードの180を優先しています。

stopMotors

機能概要元のまま：左右モーター停止
処理内容PWMを0にし方向端子をLOWにする。出力中なら逆転待ちの起点を記録。
関数形式void stopMotors()
入出力引数なし
戻り値なし
入力なし
出力左右モーター停止
ソースファイルCompletedObstacleCar.ino
呼び出し関数analogWrite / digitalWrite / millis
使用変数stopTimingActive / stoppedAt

cancelMovement

機能概要元のまま：操作解除
処理内容requested=STOP、holdActive=falseにしてモーター停止。
関数形式void cancelMovement()
入出力引数なし
戻り値なし
入力なし
出力走行解除
ソースファイルCompletedObstacleCar.ino
呼び出し関数stopMotors
使用変数requested / holdActive

checkHoldTimeout

機能概要元のまま：長押し期限確認
処理内容最終有効受信から250ms以上なら操作解除。
関数形式void checkHoldTimeout()
入出力引数なし
戻り値なし
入力lastReceivedAt / millis
出力必要なら停止
ソースファイルCompletedObstacleCar.ino
呼び出し関数cancelMovement
使用変数holdActive

getDirection

機能概要元のまま：キーから方向へ変換
処理内容上24・下82・右90・左8を方向へ変換。他はSTOP。
関数形式Direction getDirection(uint16_t command)
入出力引数uint16_t command
戻り値Direction
入力リモコンのcommand
出力方向
ソースファイルCompletedObstacleCar.ino
呼び出し関数なし
使用変数なし

sameRemote

機能概要元のまま：送信元照合
処理内容アドレス一致かつプロトコル一致を判定。NECとNEC2は同等。
関数形式bool sameRemote(uint16_t address, decode_type_t protocol)
入出力引数address / protocol
戻り値bool
入力現在と前回の送信元
出力一致判定
ソースファイルCompletedObstacleCar.ino
呼び出し関数なし
使用変数lastAddress / lastProtocol

readRemote

機能概要元のまま：リモコン受信
処理内容長押し期限→受信→異常/OK停止→同じ送信元の繰り返し→新しい方向。
関数形式void readRemote()
入出力引数なし
戻り値なし
入力IR受信D4
出力requested / holdActive更新
ソースファイルCompletedObstacleCar.ino
呼び出し関数checkHoldTimeout / cancelMovement / sameRemote / getDirection
使用変数lastCommand / lastAddress / lastProtocol

driveMotors

機能概要元のまま：通常走行
処理内容長押し中のrequestedをPWM180へ変換。逆転時は100ms停止。
関数形式void driveMotors()
入出力引数なし
戻り値なし
入力requested / holdActive
出力左右モーターPWM180または停止
ソースファイルCompletedObstacleCar.ino
呼び出し関数stopMotors / analogWrite / digitalWrite
使用変数appliedRight / appliedLeft

setupObstacleDetection

機能概要追加：センサー初期化
処理内容超音波Trigを出力、Echoと後方D0/D2を入力にし、ブザーOFF。
関数形式void setupObstacleDetection()
入出力引数なし
戻り値なし
入力なし
出力センサー端子初期化
ソースファイルCompletedObstacleCar.ino
呼び出し関数pinMode / digitalWrite
使用変数なし

updateUltrasonicState

機能概要追加：前方距離とSR1/SR2
処理内容60msごとに距離SDを測る。5cm以下SR1、5cm超～15cm以下SR2。無応答は無効。両フラグを毎回解除更新。
関数形式void updateUltrasonicState()
入出力引数なし
戻り値なし
入力Echo D3 / Trig D10
出力SD / SR1 / SR2 / distanceValid
ソースファイルCompletedObstacleCar.ino
呼び出し関数pulseIn / digitalWrite / delayMicroseconds
使用変数lastSensorAt / sensorStarted

updateRearInfraredState

機能概要追加：後方障害物
処理内容D0/D2のどちらかがLOWならIR=true、それ以外はfalse。
関数形式void updateRearInfraredState()
入出力引数なし
戻り値なし
入力後方左右センサー
出力IR
ソースファイルCompletedObstacleCar.ino
呼び出し関数digitalRead
使用変数なし

updateVehicleState

機能概要追加：最終状態M判定
処理内容RMを元のrequestedから作る。解除/無効測距/前後同時ならM0。SR1ならM1、IRならM2、それ以外RM+2。
関数形式void updateVehicleState()
入出力引数なし
戻り値なし
入力requested / holdActive / SR1 / IR / distanceValid
出力RM / M
ソースファイルCompletedObstacleCar.ino
呼び出し関数checkHoldTimeout
使用変数なし

updateBuzzerState

機能概要追加：警告ブザー
処理内容SR1またはIRは100ms周期、SR2は距離に応じ600～100ms周期。ON35ms。その他OFF。
関数形式void updateBuzzerState()
入出力引数なし
戻り値なし
入力SD / SR1 / SR2 / IR
出力D13 LOWで鳴動
ソースファイルCompletedObstacleCar.ino
呼び出し関数millis / digitalWrite
使用変数buzzerActive / buzzerStartedAt

applyObstacleMovement

機能概要追加：回避動作
処理内容M0停止。M1はPWM26で後退、M2はPWM26で前進。逆転前100ms停止。M3～6はfalseを返す。
関数形式bool applyObstacleMovement()
入出力引数なし
戻り値bool：出力処理済みならtrue
入力M / appliedRight / appliedLeft
出力回避モーター出力
ソースファイルCompletedObstacleCar.ino
呼び出し関数stopMotors / millis / analogWrite / digitalWrite
使用変数stopTimingActive / stoppedAt

setup

機能概要元の初期化＋追加呼び出し
処理内容元のモーター/IR初期化の後、setupObstacleDetectionを1行追加。
関数形式void setup()
入出力引数なし
戻り値なし
入力なし
出力全体初期化
ソースファイルCompletedObstacleCar.ino
呼び出し関数stopMotors / IrReceiver.begin / setupObstacleDetection
使用変数なし

loop

機能概要元の3行＋画像Mainの処理順を追加
処理内容readRemote→checkHoldTimeout→超音波→後方IR→車両→ブザー→回避出力。回避不要なら元のdriveMotors。
関数形式void loop()
入出力引数なし
戻り値なし
入力リモコン/センサー
出力警告と走行
ソースファイルCompletedObstacleCar.ino
呼び出し関数readRemote / checkHoldTimeout / updateUltrasonicState / updateRearInfraredState / updateVehicleState / updateBuzzerState / applyObstacleMovement / driveMotors
使用変数各状態変数
