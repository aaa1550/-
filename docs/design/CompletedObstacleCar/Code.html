CompletedObstacleCar.ino / Arduino UNO / サーボなし

この.inoをダウンロードコード・手順・設計書一式関数設計書配線・使用手順保存したフローチャート

オンライン保存した「完成コート.txt」に追加だけで統合。元の7関数・ピン・ボタン値・通常速度180は維持しています。緑の行が追加箇所です。図の通常速度50％/30％は元コード優先で180のままです。UNOコンパイル・模擬テスト済み、実機未検証です。

条件動作
前方5cm以下低速後退：PWM26
後方障害物低速前進：PWM26
前方15cm以内・後方検知ブザー。前方は近づくほど速く鳴動
OK・長押し解除・前後同時検知・測距失敗停止
障害物が解消長押し中の元の操作へ復帰

IR D4 / 右 D9・D12・D11 / 左 D6・D7・D8 / Echo D3 / Trig D10 / 後方 D0・D2 / ブザー D13

   stopTimingActive = true;  }  appliedRight = 0;  appliedLeft = 0;}void cancelMovement() {  requested = STOP;  holdActive = false;  stopMotors();}void checkHoldTimeout() {  if (holdActive &&      uint32_t(millis() - lastReceivedAt) >= HOLD_TIMEOUT_MS) {    cancelMovement();      left = -TURN_SPEED;      break;    default:      stopMotors();      return;  }  bool reversing =      (appliedRight > 0 && right < 0) ||      (appliedRight < 0 && right > 0) ||      (appliedLeft > 0 && left < 0) ||      (appliedLeft < 0 && left > 0); HIGH : LOW);  digitalWrite(RightDirectPin2, speed < 0 ? HIGH : LOW);  digitalWrite(LeftDirectPin1, speed > 0 ? HIGH : LOW);  digitalWrite(LeftDirectPin2, speed < 0 ?
