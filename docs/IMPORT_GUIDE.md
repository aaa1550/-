# インポートの使い方

画面右上の「インポート」からファイルを選択し、取り込む内容と重複IDを確認して「確認して取り込む」を押してください。

## 保存先
この端末・このブラウザ内のIndexedDBに保存します。公開サイト・GitHubリポジトリ・別端末へは送信/反映しません。同じブラウザで再読み込みした場合も取り込み内容を読み出します。ブラウザデータの削除、プライベートブラウズ終了、保存容量制限などで消える場合があります。

「サイト情報・更新方法」→「全データ・添付をJSONで保存」でバックアップしてください。別の端末ではこのJSONをインポートして利用できます。

## 対応形式
|形式|取り込み結果|
|---|---|
|JSON|records/files形式のデータ・添付バックアップを復元|
|CSV|指定した管理画面のレコードへ変換。関数名の列があるCSVは関数設計書へ変換|
|.ino / .c / .cpp / .h|コードライブラリへ登録し、原本も保存|
|画像|資料として保存。「フローチャート」を取込先に指定すると画像とフローチャートを登録|
|Office / PDF / TXT / Markdown / ZIP / draw.io|原本資料としてファイル管理へ保存|

Office/PDFなどの内容を設計項目へ自動抽出する機能はありません。HTML/Word形式の設計書はこの取り込みの対象外です。設計項目の復元にはJSONまたはCSVを使ってください。

## JSON
各管理画面のエクスポートに「JSON（再インポート用）」を追加しています。JSONテンプレートもインポート画面から保存できます。
```json
{"schemaVersion":1,"records":[{"id":"IMP-EXAMPLE-001","kind":"requirements","title":"追加要件","content":"要件の内容","status":"下書き"}],"files":[]}
```
kindはrequirements/basic/detailed/flowcharts/codes/tests/bugs/tasks/logs/foldersのいずれか。IDは英数字・ハイフン・アンダースコア・ドットで120文字までです。

## CSV
ヘッダー付きのUTF-8 CSVを使用します。ダブルクォートで囲んだ改行・カンマ・引用符に対応します。CSVにIDがない場合は自動採番し、タイトルは必須です。
関数設計書は次の列名に対応します。
ID,関数名,機能概要,処理内容,関数形式,引数,戻り値,入力,出力,ソースファイル,呼び出し関数

## 重複
同じIDは既定でスキップします。「インポート内容で置き換える」を選ぶとこのブラウザ内の内容を置き換えます。種別が異なるIDの上書きは拒否します。検証エラーがある場合、取り込み操作前には何も保存しません。IndexedDB書き込みはトランザクションでまとめて処理します。

## 制限と解除
1回20ファイル。添付は1件20MB、合計50MBまで。JSONバックアップは80MBまでです。
「サイト情報・更新方法」→「このブラウザの取り込みを解除」でローカルの取り込みを全件解除できます。必要なデータは先にJSONで保存してください。公開データとGitHubの履歴は変更されません。
